Entry for the [Fridge Roast: One Line, Biggest Laugh bounty on make.fun](https://make.fun/competitions/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb).

`main.ts` writes one roast of a smart fridge to `/output/entry.txt`: a single
line, 200 characters at most, checked against the gate before writing and
read back to confirm the bytes landed intact.

> My fridge's camera mistook the butter for a person and now sends me a daily notification that 'he' hasn't moved in three days.

Stdlib only, no network, deterministic. Run with `node main.ts` (or
`node main.ts --check` to validate the line without writing).
